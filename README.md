## Project Description

Python Based Student Academic Management System is a console based application designed to manage students academic information.
It allows user to add, search, update, delete, and display student records, as well as generate academic statistics.
The system manages students grades and automatically calculates their averages, academic status, and classification.
Student data is stored in a file so it can be retrieved and used in future program sessions.

## Features

- Add new students.
- Search for students by ID or name.
- Update student grades.
- Delete student records.
- Display student academic reports.
- Calculate student averages automatically.
- Determine student status and classification.
- Display academic statistics.
- Store student data in a file for future use.

## How to Run

1. Make sure Python is installed on your device.
2. Download or clone the project files.
3. Open the project folder.
4. Run the `Main.py` file:

```bash
python Main.py
```
